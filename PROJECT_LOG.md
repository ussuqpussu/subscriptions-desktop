# PROJECT_LOG — Подписки (ПК + PWA)

Дата: 2026-11-26. Учебный проект Артёма и Вовы. Критерии: идея 10, реализация 10, тестирование 10, презентация 10.

## Состояние
- Приложение: React + TS + Vite, одна кодовая база для PWA (телефон) и Electron (.exe для Windows 10/11 и Windows 7).
- Сайт и слайды: `site/`, публикуются на GitHub Pages.
- Сборки .exe: GitHub Actions, workflow «Сборка .exe для Windows».

## Дизайн-план версии для ПК (редизайн 2026-11-26)
Дизайн-чтение: «рабочее окно личных финансов для студента на ПК; язык спокойный, приборный; опора на существующую дизайн-систему приложения (токены, акцент по выбору пользователя) и раскладку настольных финансовых приложений: боковая навигация + рабочая область».

Ручки: вариативность 3, движение 4, плотность 6 (финансы и рабочий инструмент: доверие и читаемость важнее находок, 3B.2).

Цвет: из существующей системы, не новый — акцент пользователя (по умолчанию #FFB4A2 в тёмной теме / #C02A52 в светлой), фон и поверхности из tokens.css, статусы зелёный #30D158, жёлтый, красный #FF453A.
Шрифты: системные — Segoe UI Variable на Windows, SF Pro на Apple. Выбор осознанный: родной для ОС шрифт делает .exe похожим на настоящую программу Windows, кириллица полная.

Раскладка (ширина окна ≥ 960 px):
```
+-----------+--------------------------------------+
| Подписки  |  Главная                     [поиск] |
|           |  +---------------+ +----------------+|
| > Главная |  | Траты в месяц | | Ближайший      ||
|   Статист.|  +---------------+ +----------------+|
|   Календ. |  Подписки (12)              [фильтр] |
|           |  | ● Spotify   199 ₽   через 3 дня [✓]|
| [+ Добав.]|  | ● iCloud+   149 ₽   …            |
|  ...      |                                      |
| Синхр.    |                                      |
| Оформл.   |                                      |
+-----------+--------------------------------------+
```
Уже́ 960 px — прежний мобильный вид (верхняя панель + нижняя стеклянная панель).
Календарь ≥ 1100 px: месяц слева, события дня справа. Статистика: две колонки.
Окна (sheet) на ПК — по центру, закрываются Esc и кликом мимо.

Что делает экран «этим»: лампочки статуса у каждой строки и кнопка «Оплачено» прямо в строке при наведении — главное действие приложения в один клик.

Проверка плана против брифа: боковое меню — дефолт для десктоп-приложений, но здесь оправдано: три раздела + 6 служебных действий не влезают в верхнюю панель, а нижняя панель на ПК неестественна. Новую палитру не вводим: пользователь уже выбирает акцент в «Оформлении» (правило 0 о палитре).

## Функции ПК
- Уведомления Windows (Notification API в Electron) вместо веб-пушей: считаются на устройстве из того же расписания, что и пуши.
- Автозапуск вместе с Windows (переключатель).
- Горячие клавиши: Ctrl+N новая, Ctrl+F поиск, Ctrl+1/2/3 разделы, Esc закрыть окно.
- Файлы (копия, .ics) — обычное окно сохранения.
- Демо-данные «Заполнить примером» на пустом экране.

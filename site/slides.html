Проблема

  • Подписок много: музыка, кино, облако, игры
  • Списания незаметные — легко забыть и переплатить
  • Пробный период заканчивается, и деньги уходят сами

Решение

  • Все подписки в одном списке
  • Лампочки: зелёная, жёлтая, красная
  • Итог в рублях по курсу ЦБ
  • Предупреждение о конце пробного периода

Чем отличается

  • 75 российских и зарубежных сервисов с логотипами
  • Календарь списаний с оплатой в один клик
  • Шифрованная синхронизация ПК ↔ iPhone
  • Без регистрации и рекламы, работает офлайн

Как сделано

  • React + TypeScript + Vite — интерфейс
  • Electron — приложение .exe для Windows
  • Cloudflare Workers — синхронизация, логотипы, каталог
  • GitHub Actions — автосборка установщика

Тестирование

  • 142 автотеста, все проходят
  • Даты платежей, 31-е число в коротком месяце
  • Курсы валют, экспорт в календарь, резервные копии
  • Синхронизация и шифрование

Команда

  • Вова — автор идеи
  • Артём — разработка

# Подписки: трекер подписок для Windows

Учебный проект Артёма и Вовы. Приложение для ПК (.exe) на основе веб-приложения «Подписки», плюс сайт проекта и презентация.

## Что внутри
- `src/`: приложение (React + TypeScript + Vite).
- `electron/`: обёртка для Windows, раздаёт приложение с `127.0.0.1:4173`.
- `worker/`: сервер на Cloudflare (синхронизация, логотипы, каталог).
- `site/`: сайт проекта (`index.html`) и презентация (`slides.html`).

## Команды
- `npm run dev`: запуск в браузере.
- `npm test`: автотесты.
- `npm run desktop`: запуск окна Electron.
- `npm run dist:win`: установщик `.exe` в `release/` (собирать на Windows).

## Как получить .exe
Поставить тег `v1.0.0` и отправить его на GitHub: Actions соберёт установщик и выложит его в Releases. Можно запустить вручную: Actions → «Сборка .exe для Windows» → Run workflow, а файл скачать в Artifacts.

## Ограничения версии для ПК
Пуш-уведомления в .exe отключены, потому что Electron не поддерживает веб-пуши. Напоминания работают через экспорт в календарь.
